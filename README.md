# Employee Management & Payroll System (PWA)

ระบบจัดการพนักงาน เช็คชื่อ และคำนวณเงินเดือนขนาดเล็กที่ออกแบบมาสำหรับธุรกิจขนาดเล็ก (SMEs) โดยมีหน้าจอแสดงผลสไตล์ **Solid iOS 27** ที่ดูพรีเมียม สบายตา ใช้งานง่ายผ่านโทรศัพท์มือถือ

## ฟีเจอร์หลัก (Key Features)

- **ระบบฐานข้อมูลแบบ Hybrid**: ทำงานแบบ Offline ด้วย LocalStorage เพื่อความรวดเร็ว และมีระบบ **Sync ไปยัง Google Sheets อัตโนมัติ (Audit Log)** เพื่อป้องกันข้อมูลสูญหายและตรวจสอบประวัติย้อนหลังได้ตลอดเวลา!
- **Progressive Web App (PWA)**: รองรับการติดตั้งแอปพลิเคชันลงบนหน้าจอโฮม (Home Screen) ของมือถือ เสมือนใช้งานแอปพลิเคชันจริง
- **การจัดการพนักงาน (Employee Management)**: เพิ่ม ลบ แก้ไข ข้อมูลพนักงาน พร้อมตั้งค่าสีหรืออีโมจิประจำตัว
- **ระบบเช็คชื่อ (Attendance)**: บันทึกการมาทำงาน ขาด ลา มาสาย และสรุปยอดเป็นรายเดือน
- **ระบบกระเป๋าเงิน (Wallet/Draws)**: จัดการการเบิกเงินล่วงหน้า หรือหักค่าอาหารในแต่ละวัน พร้อมหน้าต่างใบเสร็จสุดสวย
- **ระบบเงินเดือน (Payroll)**: คำนวณเงินเดือนให้โดยอัตโนมัติ (หักการเบิก, ขาด, ลา, สาย) รองรับการแบ่งจ่ายเป็น 2 รอบ (วันที่ 15 และสิ้นเดือน)
- **UI/UX พรีเมียม**: ออกแบบหน้าตาแบบ iOS พร้อมสลิปเงินเดือนและใบเบิกสไตล์ Apple Wallet

## โครงสร้างไฟล์
- `index.html`: ไฟล์หลักของหน้าเว็บและโครงสร้าง HTML
- `style.css`: รวบรวมสไตล์ (CSS) ทัังหมด โทนสี อนิเมชัน และการจัดรูปแบบตามฉบับ iOS
- `app.js`: โค้ดโปรแกรมทั้งหมด (จัดการฐานข้อมูล สร้าง UI คำนวณเงิน และส่งข้อมูลไป Google Sheet)
- `sw.js`: Service Worker สำหรับทำระบบออฟไลน์และ PWA
- `manifest.json`: ข้อมูลแอปพลิเคชันสำหรับตอนติดตั้ง (PWA)

## วิธีอัปโหลดขึ้น GitHub และใช้งานฟรี (GitHub Pages)

เนื่องจากโปรเจกต์นี้เขียนด้วย HTML/JS/CSS ล้วนๆ คุณสามารถนำไปโฮสต์ (Host) บน GitHub ได้ฟรีตลอดชีพ:

1. เข้าเว็บ [GitHub.com](https://github.com/) ล็อกอิน และกดสร้าง **New Repository** (ตั้งชื่อเช่น `my-erp`)
2. ในหน้า Repository ของคุณ ให้กดลิงก์ **"uploading an existing file"**
3. ลากไฟล์ทั้ง 7 ไฟล์ในโฟลเดอร์นี้ (`index.html`, `app.js`, `style.css`, ฯลฯ) ไปวาง แล้วกดปุ่มสีเขียว **Commit changes**
4. ไปที่เมนู **Settings** (การตั้งค่า) ของโปรเจกต์
5. เลื่อนเมนูด้านซ้ายมาที่ **Pages**
6. ภายใต้หัวข้อ Build and deployment ตรงช่อง **Source** ให้เปลี่ยนเป็น **`main`** (หรือ master) แล้วกด **Save**
7. รอระบบประมวลผลประมาณ 1-3 นาที คุณจะได้ลิงก์เว็บไซต์ของแอปคุณ (เช่น `https://ชื่อคุณ.github.io/my-erp/`)

## วิธีนำไปใช้งานบนมือถือ (Add to Home Screen)
1. ส่ง URL ที่ได้จากขั้นตอนด้านบนเข้าไลน์ หรือแชทของตัวเอง
2. เปิด URL นั้นผ่านเบราว์เซอร์ **Safari (สำหรับ iPhone)** หรือ **Google Chrome (สำหรับ Android)**
3. กดปุ่ม Share (ส่งต่อ) แล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. ไอคอนแอปจะไปปรากฏบนหน้าจอมือถือของคุณ สามารถกดใช้งานได้เหมือนแอปพลิเคชันปกติเลยครับ!
